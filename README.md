# Готова в роддом — PWA

Загрузите все файлы и папку `icons` в корень GitHub-репозитория.

Важно:
- главный файл должен называться `index.html`;
- `manifest.json`, `app.js` и `sw.js` должны лежать рядом;
- папка `icons` должна содержать обе PNG-иконки.

После публикации GitHub Pages:
1. Откройте сайт в Safari на iPhone.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Приложение установится как отдельная иконка.

После первого открытия онлайн приложение сможет запускаться офлайн.
